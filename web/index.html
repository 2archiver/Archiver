3.1Latest2026-09-26
Built-in AI, without a model server
  • Local replies no longer wait for the server. Working Stop and smoother streaming.
  • Restored conversation context, local comparisons, formatting, text extraction, and corrected calculator precedence.
  • Built-in, self-hosted AI runtime. Complex requests automatically prepare a compact 0.5B model in a browser worker; no manual download or API key.
  • Browser-cached model assets, Data Saver/offline guards, bounded initialization, Stop during loading, and instant fallback. No weights, GPU inference, or model storage on Render.
  • Mobile keyboard sizing, larger touch targets, accessible zoom, and a calmer chat layout.
